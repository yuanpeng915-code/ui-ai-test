# 用例生成沉淀笔记索引

> 每个模块的生成经验、踩坑记录、标准流程模板，按模块拆分存放。
> 生成用例前先查对应模块笔记，生成后追加新经验。

## 笔记编写规范

每个模块笔记包含:
- 业务约束例(上游操作对下游业务的影响。例如创建B/S资产需要额外填写http服务地址)
- 参数说明(某个参数必须按格式传参，例如：备注最大255个字等)

## 更新规则

- 每次生成新用例并验证通过后，更新对应模块笔记
- 用户纠正生成错误后，*先清理就内容*在把纠正内容写入笔记
- 笔记用中文，简洁为主，不写废话
